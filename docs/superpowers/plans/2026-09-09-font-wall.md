# All-Fonts Wall + Light/Dark Toggle + Copy Buttons

> Implementation plan for three home-page UX changes.

**Goal:** Show typed text rendered in all 328 fonts on `/` (ascii.today style), add a light/dark toggle in the header, and add per-font copy buttons.

**Architecture:** New batch API `POST /api/generate-all` renders text across all curated fonts server-side; a new `FontWall` client component debounces input and renders a filterable grid. `Generator` is trimmed to text/width/layout only. `ModeToggle` mirrors `LocaleToggle` (CustomEvent-synced with the `D` hotkey).

**Tech Stack:** Next.js 16 App Router, TS 7 strict, npm, better-sqlite3. No new deps.

## Global Constraints

- Conventional commits lowercase `type(scope): subject`.
- No emojis in UI copy (☀/☾/◐ are typographic glyphs, acceptable).
- `tsc --noEmit` is lint; co-located `*.test.ts`.
- `'use client'` on client components; `@/*` alias.
- API error shape `{ error, code }` via `lib/api.ts`; `force-dynamic`.
- Rate limit via `getRateLimiter` + `applyRateLimitHeaders`.
